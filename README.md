# Portfolio BTS SIO – Fadel Bamba

Portfolio de Fadel Bamba, étudiant en BTS SIO option SLAM à l'Institution Saint-Aspais (Melun).

## Contenu
- Accueil, formation & parcours, compétences techniques
- Stage de 1re année : refonte du site de l'association Musidanses (juin–juillet 2026)
- Stage de 2e année : à venir
- Projets (Koo2fourchette, projets de 2e année à venir)
- Procédures informatiques, veille technologique (à compléter)

## Structure
```
index.html      page du portfolio
style.css       mise en forme (couleurs dans les variables :root)
images/         photos et logos
documents/      CV, lettre de motivation, rapport de stage, procédures
```

## Ajouter un projet
Dans `index.html`, section `#projets`, copier un bloc `<article class="project-card">` et remplacer le titre, le texte et le lien.
